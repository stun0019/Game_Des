# 月光食堂物語

以 1280 × 720 為主畫布的橫向時間管理料理遊戲原型。目前已完成第一章的 Loading、章節地圖、五個小關卡與日式深夜拉麵餐車營業畫面。

## 啟動

在專案資料夾啟動本機伺服器：

```powershell
python -m http.server 4173
```

然後前往 <http://127.0.0.1:4173>。

## 章節一：照顧疲憊的上班族

主題餐車為「日式深夜拉麵車」，共五個小關卡：

1. `1-1` 開始營業的第一天
2. `1-2` 下班後的一碗暖湯
3. `1-3` 突如其來的加班潮
4. `1-4` 深夜最後一班車
5. `1-5` 上班族的感謝祭

五關分別使用教學出餐、滿意度、尖峰出餐、分數連擊及三波套餐模式，並套用不同的夜色情境。

## 場景素材

專案使用的原創場景素材位於 `assets/scenes/`：

- `loading-night.webp`
- `chapter-01-map.webp`
- `ramen-truck-night.webp`
- `office-workers.webp`

素材以生成式圖像製作，參考休閒料理遊戲的立體度、材質與景深，但未使用既有遊戲角色、商標或原始素材。

## 存檔

遊戲進度、星級、金幣、升級與道具儲存在瀏覽器 Local Storage。

## 開發規則

- 不直接提交或推送 Git；提交前需由專案擁有者確認。
- 後續章節可替換獨立餐車與場景素材，例如台式、韓式或西式主題。
- 每個新主題預設規劃五個小關卡。
