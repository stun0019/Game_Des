# 月光食堂物語

以時間管理料理遊戲為核心的網頁版遊戲原型。

## 啟動

直接使用瀏覽器開啟 `index.html`，或在此資料夾啟動本機伺服器：

```powershell
python -m http.server 4173
```

然後前往 <http://127.0.0.1:4173>。

## 第二版內容

- 2 間主題餐廳、8 個可解鎖關卡
- 提供、得讚、分數、套餐及客人人數限制模式
- 每位客人可同時點 1～2 道料理
- 選餐、烹調、盛盤、加料及指定客人出餐
- 料理燒焦、丟棄、客人離開等可配置失敗條件
- 具有時限的 Combo 系統
- 永久金幣、餐廳設備升級與本機進度保存
- 3 名具備不同被動與主動技能的夥伴
- 防焦、加速及分數紅利開張道具
- 關卡評星、成就日誌與每日挑戰

遊戲進度儲存在瀏覽器的 Local Storage。
